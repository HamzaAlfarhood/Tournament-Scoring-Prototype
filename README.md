# Tournament Scoring Prototype 🏆

A lightweight, efficient Windows Forms application built with **C#** and **.NET** to manage and calculate tournament scores dynamically. This prototype serves as a foundation for sports management systems or competitive gaming leaderboards.

---

## 🚀 Overview
**Tournament-Scoring-Prototype** is designed to simplify the process of tracking points, wins, losses, and draws in a tournament setting. It provides a clean UI for data entry and real-time score updates.

## ✨ Key Features
* **Dynamic Scoring:** Automatically calculates total points based on match outcomes.
* **Modern .NET Architecture:** Built using the latest Visual Studio `.slnx` solution format.
* **WinForms UI:** User-friendly interface for quick interaction.
* **Scalable Core:** Easily adaptable for different types of sports or e-sports rules.

## 📁 Project Structure
The project follows a clean C# directory layout:
* `MainForm.cs`: The core logic and UI interaction.
* `Program.cs`: The entry point of the application.
* `v1.csproj`: Project configuration and dependencies.

## 🛠️ Requirements
* **Operating System:** Windows 10/11.
* **Framework:** .NET 6.0 or higher.
* **IDE:** Visual Studio 2022 (Recommended).

## 📥 Installation & Usage
1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/HamzaAlfarhood/Tournament-Scoring-Prototype.git](https://github.com/HamzaAlfarhood/Tournament-Scoring-Prototype.git)
    ```
2.  **Open the project:** Launch `v1.slnx` in Visual Studio.
3.  **Build & Run:** Press `F5` to compile and start the application.
